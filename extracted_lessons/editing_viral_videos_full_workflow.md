## What The Tutorial Teaches

The tutorial frames viral editing as a full workflow, not a pile of effects. The useful agent knowledge is: choose an audience and style, test the idea/script before editing, add a deeper secondary story where useful, color-code the script into asset needs, assemble voiceover and music early when the edit needs vibe and beat timing, layer visuals by script highlights, sketch animations before building them, use text/overlay/effect presets only when they support the message, sound-design in a focused pass, correct color late, learn one new technique per video, and publish once the edit clears a defined quality threshold.

## Agent Decision Rules

- Do not try to save a weak idea or script with editing. First ask whether the target audience would click and care.
- Match editing style to the audience and creator tone; viral energy for one audience can feel wrong for another.
- Add a secondary story layer when the main tutorial, challenge, or explainer needs emotional depth or progress.
- Color-code the script before editing so each sentence has an intended asset type or visual job.
- Gather videos, images, screen recordings, music, SFX, overlays, and presets before heavy timeline work when the script is known.
- Use music early only when it clarifies vibe and supports beat-aware cutting; keep the licensing and dialogue-mix checks.
- Sketch every nontrivial animation before building it. Use simple tools for simple animations and After Effects/Remotion for complex scenes.
- Use text in three jobs: captions for comprehension, center/emphasis text for ideas captions cannot carry, and scene-attached text when it belongs to a screen/wall/object.
- Use overlays as highlighters, transitions, or texture only when they do a job; do not let electric/dust/light-leak effects become random decoration.
- Do an isolated SFX pass when needed: temporarily mute other tracks, place sounds against visible actions, then bring dialogue/music back and lower SFX until they support rather than annoy.
- Preserve meaningful pauses. Fast pacing is useful, but cutting every breath can remove story.
- Keep learning one new technique per project, but set a publish threshold so perfectionism does not trap the edit forever.

## Timeline Patterns

- `audience_fit -> idea_gate -> script_outline -> secondary_story -> structure -> script_color_code -> asset_gather -> voiceover -> music_vibe -> rough_visual_layering -> animation_sketch -> animation_build -> second_pass_cut -> motion_text_overlay -> isolated_sfx_pass -> color_correction -> publish_qc`
- `sentence -> color_category -> asset_type -> collected_asset -> timeline_layer -> visual_job -> caption_suppression_or_support`
- `sketch_animation -> choose_simple_or_advanced_tool -> build_shapes_text_paths -> sync_to_voiceover -> add glow_or_texture_if_needed -> export_high_enough_resolution -> timeline_alignment`
- `rough_cut_review -> add_needed_visuals -> remove_boring_lines_or_bad_jokes -> preserve_worthwhile_space -> effects_with_job -> final_sfx_mix -> publish_threshold`

## Implementation Notes

- Premiere: create an organized project, import voiceover first, trim based on script, optionally add licensed/platform-safe music early for vibe, layer assets based on script colors, then use Transform keyframes, text layers, overlays, SFX, Lumetri, and export QC.
- After Effects: use text, shapes, and pen paths from a sketch; add typewriter text, Trim Paths movement, glow, and easing only after the animation idea is clear.
- Remotion: represent the workflow as structured data: audience, ideaGate, scriptBeats, secondaryStory, colorTags, assetNeeds, musicCue, visualLayers, animationPlans, sfxPass, colorPass, and publishThreshold.
- ffmpeg: use for rough timing previews, contact sheets, loudness checks, overlay tests, subtitle/caption burn-ins, and final probe/decode checks; complex animations should be pre-rendered or rebuilt in Remotion.
- CapCut/Canva equivalent: for simple animations, build text/shapes/graphics in a simple tool, export at high enough resolution for later zooms, then place into the edit and verify phone-size readability.

## Mistakes And QC

- Do not apply a style that belongs to a different audience.
- Do not start editing before the idea, script, and progress structure are strong enough.
- Do not gather random assets; each asset should map to a script beat.
- Do not add music early and forget to re-check dialogue clarity later.
- Do not export simple animations too low-resolution if the edit will zoom into them.
- Do not caption every sentence if text popping every second becomes irritating.
- Do not place text, overlays, and captions with no focal hierarchy.
- Do not sound-design with dialogue/music muted and then skip the full-mix check.
- Do not keep learning new techniques forever inside one project; publish when the edit meets the defined QC bar.
