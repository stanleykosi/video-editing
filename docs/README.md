# Documentation

Engine documentation lives under `engine/`:

- `engine/ARCHITECTURE.md` - subsystem ownership and dependency direction.
- `engine/PUBLIC_API.md` - supported Python and CLI interfaces.
- `engine/RENDERING.md` - compiler, graph, backend, cache, and delivery behavior.
- `engine/AUDIO.md` - multitrack audio model and processing.
- `engine/CAPTIONS.md` - caption tracks, ASS, typography, and layout checks.
- `engine/GRAPHICS.md` - component registry and Remotion bridge.
- `engine/MIGRATION.md` - legacy and interchange migration.
- `engine/LEGACY_BOUNDARY.md` - canonical, compatibility, and workflow ownership.
- `engine/TESTING.md` - verification strategy and evidence.
- `engine/PROGRESS.md` - implementation status and known risks.

Editorial guidance is intentionally separate under `../knowledge/`.
