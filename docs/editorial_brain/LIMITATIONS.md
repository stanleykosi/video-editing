# Editorial Brain Limitations

## Reduced in this update

- Project-root `.env` credentials were previously invisible to providers. They
  now resolve securely; Deepgram is detected from `.env`.
- Repository knowledge was previously a duplicated file-routing layer. It is
  now deterministically compiled into a checked source-neutral principle,
  recipe, conflict, and QC graph, then synthesized into a per-video
  `TasteProfile`.
- Synthetic scenarios previously omitted knowledge influence. All ten now gate
  consolidation, contextual taste relevance, source-neutral identity, and
  engine compilation.

## Remaining evidence and perception limits

- Deterministic vision measures quality, motion and boundaries but cannot fully
  understand subtle visual meaning. An optional multimodal provider improves
  semantic comparison; it cannot invent times or override source evidence.
- ASR word boundaries can drift from the waveform. Structural padding and
  never-cut-inside-word constraints reduce but cannot eliminate provider error.
- Speaker identity, reactions and synchronization remain conservative when
  source evidence is weak. The Brain will flag ambiguity rather than invent it.
- Missing, poor, watermarked or visually unrelated source material cannot be
  repaired by editorial policy. External asset sourcing remains outside the
  Brain.

## Taste and knowledge limits

- The base is structurally deduplicated and all detected conflicts are resolved
  contextually. It can still have domain or cultural blind spots where the
  repository contains no applicable knowledge.
- Deterministic routing understands structured applicability and lexical/domain
  relevance; it is not equivalent to a senior editor interpreting every nuance
  of every tutorial in a new cultural context.
- Compiled weights are deliberately bounded. Knowledge cannot weaken hard
  source, timing, rights, lock or engine-validation constraints.
- Current golden scenarios test expected editorial behaviors and knowledge
  influence. They are not blind human preference studies and do not establish
  universal “human-level taste.”
- No persistent personal preference model is calibrated from ranked A/B edits.
  Per-video uniqueness currently comes from the brief, source capabilities,
  explicit style terms, and bounded measurable reference grammar.
- Negative reference edits are not required by the canonical base. They would
  improve future preference calibration, especially for subtle comedy,
  cultural timing, and deliberately transgressive style.

## Deliberately separate future systems

- No independent post-render Editorial Critic or automated creative revision
  loop exists yet.
- No YouTube retention/analytics learning, creator preference learning,
  publishing, research, thumbnail optimization or automatic knowledge updates
  are implemented.
- Presentation knowledge influences intent and policy, but full style-layer
  execution remains shared with the existing knowledge compiler, Remotion,
  HyperFrames and engine presentation systems.

## Runtime and provider limits

- Deepgram requires network access and consumes provider quota when actually
  transcribing. Configuration detection does not make a paid call.
- OpenAI is optional and is used only for structured frame/contact-sheet
  understanding, semantic relevance, narrative roles and close candidate
  comparisons. When its API key is absent, the production environment factory
  uses a fresh authenticated Codex sub-agent for each batched judgment. The
  sub-agent is ephemeral, read-only, schema-constrained and cannot create time
  ranges or timeline operations.
- Live cloud quality, rate limits, latency and cost cannot be verified in the
  offline baseline lane. Credentialed smoke tests remain opt-in.
- The Codex fallback has higher startup/context overhead than a direct semantic
  API call and consumes the signed-in Codex account's inference allowance. It
  requires the Codex CLI, a valid ChatGPT/Codex login and network access; if any
  is absent it fails with a typed unavailable result rather than fabricated
  analysis. Service-side model changes can alter uncached judgments, so final
  reproducibility still depends on cached provider responses.
- Blender remains an optional presentation runtime. The repository's locked
  Manim 0.20.1 environment is auto-discovered and release-doctor validated; it
  is not required for editorial decision planning but is ready for technical
  animation.
- Reference analysis extracts measurable grammar and never copies a sequence;
  subtle cultural or comedic style may require human interpretation.
