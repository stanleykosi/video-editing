# Technique Cards

Technique cards are structured editorial knowledge grouped by their declared
`category`. The directory name and JSON `category` must agree.

Cards describe when and how a technique may be used, implementation options,
constraints, and QC checks. They are not executable engine effects and must not
encode mandatory creative decisions.

Use `_template.json` for new cards and update `knowledge/playbooks/`,
`knowledge/presets/`, or `knowledge/quality/editorial_checklists/` when a card
changes broader guidance.
