# Asset Resource Platforms For Agent Video Creation

Research date: 2026-05-28

Purpose: give future agents a vetted map of where to source or generate stock
images, stock footage, public-domain/Creative Commons footage, icons, maps,
charts, music, SFX, style packs, templates, and motion graphics for videos made
from scratch.

## Recommendation

Use a layered stack rather than one platform:

1. Free/API first pass: Pexels, Pixabay, Openverse, Wikimedia Commons, NASA,
   Library of Congress, Smithsonian, The Met, Internet Archive, National
   Archives, Freesound, LottieFiles, Iconify, Natural Earth, and open data APIs.
2. Generated/programmable layer: OpenAI Images API, Adobe Firefly Services,
   Stability AI, Replicate/fal.ai, Vega-Lite, Datawrapper, Natural Earth, and
   OpenStreetMap-derived providers when the project needs custom visuals rather
   than found assets.
3. Paid/API production layer: Storyblocks API, Shutterstock API, Pond5 API, or
   Adobe Stock API if the account has Enterprise access.
4. Human-curated style/template layer: Envato Elements, Motion Array, Mixkit,
   and specialist packs such as AEJuice, Mister Horse, MotionVFX, ProductionCrate,
   or aescripts after manual license verification.

For this repo, the best default is:

- B-roll/images: Pexels + Pixabay + Openverse.
- Historical/science/art visuals: NASA + Library of Congress + Smithsonian +
  The Met + Wikimedia Commons.
- SFX: Freesound filtered to CC0/CC BY first, then Pixabay SFX.
- Music: Pixabay/Mixkit for free tests; Storyblocks/Pond5/Envato/Motion Array
  for licensed production; premium manual libraries only when a specific track
  quality is needed.
- Motion graphics/style packs: Motion Array + Envato + Mixkit + LottieFiles.
- Fully automated paid stock: Storyblocks API is the most complete first target
  because it explicitly supports image, video, and audio API testing.
- Generated images: use OpenAI Images API or Adobe Firefly first when brand
  safety/provenance matters; use Stability AI, Replicate, fal.ai, or other model
  hosts only after checking the exact model/account terms.
- Public-domain/CC footage: use Internet Archive/Prelinger, National Archives,
  Wikimedia Commons, NASA, and Library of Congress, but verify rights on every
  item before editing or monetizing.
- Icons: prefer local/open icon libraries such as Iconify, Lucide, Heroicons,
  Tabler, or Phosphor; use Noun Project/Iconfinder only with API/license tracking.
- Maps: generate maps from Natural Earth/public geodata where possible; use
  OpenStreetMap-derived services with visible attribution and respect tile/geocode
  usage policies.
- Charts: generate charts from data using Vega-Lite/Observable Plot/Chart.js or
  Datawrapper; do not screenshot unsourced charts unless the license and data
  provenance are clear.

## Agent Access Reality Check

Future agents should not treat this file as "every platform is instantly
downloadable." Before sourcing assets, classify the source by access tier:

| Access Tier | What The Agent Can Do | Good Examples | Notes |
| --- | --- | --- | --- |
| No-key/direct public access | Search/fetch metadata and download files directly with HTTP/API tools, then save them into the project folder. | Wikimedia Commons, NASA Image and Video Library, Library of Congress, The Met, Internet Archive, Natural Earth, Iconify public API, many open data APIs. | Still verify item-level license/rights and write an asset manifest entry. Public does not always mean commercially safe. |
| Free API key/account required | Use the source only if the key exists in `.env` or the user provides it. | Pexels, Pixabay, Unsplash, Freesound, Datawrapper, Mapbox/MapTiler, Noun Project, Iconfinder. | Agents must not invent credentials or scrape around missing API access. |
| Paid/subscription/API agreement required | Search/download only after the user confirms the account and license. | Storyblocks, Shutterstock, Pond5, Adobe Stock, Envato Elements, Motion Array, Artlist, Epidemic Sound, Soundstripe, Musicbed. | Watermarked previews are acceptable for planning only, never final export. |
| Generated by agent/tooling | Create new assets from prompts, code, or data, then log generation/source details. | OpenAI Images, Adobe Firefly, Stability AI, Replicate/fal.ai, Vega-Lite charts, Natural Earth maps, local icon rendering. | Generated assets need prompt/model/date provenance; factual videos must not present generated images as real evidence. |

As a practical Codex-style agent in this workspace:

- I can directly download no-key public assets into this repo when the license
  permits it.
- I can use API-key sources if the relevant key is available in the environment
  or the user provides it.
- I can generate images when an image-generation tool/API is available, then
  store the output as a project asset if the tool exposes a downloadable file.
- I can render icons, maps, and charts locally from SVG, geodata, and CSV/API
  data once the source data or package is available.
- I cannot legally bypass paywalls, subscriptions, watermarks, login walls, or
  license restrictions just because a preview can be seen in a browser.

## Generated Images

Generated images are best treated as source assets with their own provenance,
not as anonymous stock. They are useful for thumbnails, concept frames, scene
plates, cutaway illustrations, textures, transparent objects, and stylized
backgrounds. For factual/documentary videos, agents must label generated visuals
internally and avoid implying they are real archival evidence.

| Platform | Best For | Agent Access | License / Risk Notes |
| --- | --- | --- | --- |
| OpenAI Images API | Custom stills, transparent assets, edits, variations, thumbnails, style frames | API. | Strong default for agent-created visuals. Log prompt, model, size, date, input references, and project use. Follow current OpenAI policy and do not present generated images as real footage. Source: https://platform.openai.com/docs/guides/image-generation |
| Adobe Firefly Services | Brand-safe commercial imagery, enterprise-safe variants, creative production workflows | API, generally business/enterprise oriented. | Good when commercial safety matters more than lowest cost. Use public-domain and Creative Commons footage when the video needs history,
news context, evidence, science/space material, old industrial footage,
geography, or archival texture. The rule is per-item verification: platform-level
access does not mean every file is safe for every use.

| Platform | Best For | Agent Access | License / Risk Notes |
| --- | --- | --- | --- |
| Internet Archive / Prelinger Archives | Archival films, public-domain industrial films, historical b-roll, old ads, educational films | Advanced search and metadata APIs. | Many items are public domain or openly licensed, but rights vary. Manifest must include item URL, collection, license/rights field, and downloaded file identifier. Source: https://archive.org/developers/metadata-schema/index.html and https://archive.org/advancedsearch.php |
| National Archives Catalog | U.S. government archival video, photos, documents, war/history material | Catalog API and bulk metadata/media access. | U.S. federal records are often public domain, but restrictions and third-party materials can exist. | Library of Congress | Historical footage, maps, stills, audio, public collections | Public JSON/YAML API. | Rights vary by item. Many public-domain collections exist, but agents must read item rights metadata before final use. Source: https://www.loc.gov/apis/json-and-yaml/ |

## Music And SFX Guidance

- Default free SFX: Freesound filtered to `license:"Creative Commons 0"` or
  CC BY when attribution is acceptable. Avoid CC BY-NC for monetized videos.
- Default free music/SFX: Pixabay and Mixkit for drafts, placeholders, and
  low-risk social work after license check.
- Default paid production audio: Storyblocks, Pond5, Envato, or Motion Array
  because they combine broad search with stock-video workflows.
- Premium emotional music: Artlist, Musicbed, Epidemic Sound, Soundstripe, and
  PremiumBeat are worth manual use when the music choice carries the edit.
- Always store music license certificates, cue sheets where available, track
  title, composer/artist, PRO status, Content ID notes, and download date.
- Do not use random "copyright-free music/SFX" YouTube channels unless the
  original site/license can be verified outside YouTube.

## Agent Operating Rules

1. Prefer official APIs over scraping.
2. Never download paid assets unless the user has provided account/API access
   and the license permits the intended project.
3. Never use watermarked previews in final exports.
4. Log every asset in a project manifest:
   - `source_platform`
   - `asset_id`
   - `asset_title`
   - `creator`
   - `source_url`
   - `download_url`
   - `license_name`
   - `license_url`
   - `downloaded_at`
   - `allowed_use`
   - `restrictions`
   - `local_path`
   - `used_in_timeline`
5. For generated images/video/audio, also log:
   - `generation_provider`
   - `model`
   - `model_version`
   - `prompt`
   - `negative_prompt`
   - `seed`
   - `input_references`
   - `generation_date`
   - `policy_or_license_notes`
6. For chart/data visuals, also log:
   - `data_source`
   - `query_url`
   - `retrieved_at`
   - `units`
   - `date_range`
   - `transformations`
   - `chart_spec_path`
7. For maps, also log:
   - `map_data_source`
   - `tile_or_static_map_provider`
   - `geocoder`
   - `attribution_text`
   - `bounds_or_places`
   - `style_or_renderer`
8. For icons, also log:
   - `icon_collection`
   - `icon_name`
   - `package_version`
   - `rendered_format`
9. For CC/open assets, prefer CC0/public domain first, then CC BY with
   attribution. Avoid NC/ND licenses for commercial, monetized, or remix-heavy
   work.
10. For identifiable people, trademarks, logos, buildings, medical/legal/political
   topics, and sensitive subjects, prefer paid commercially released stock or
   public-domain materials with clear context.
11. Editorial-only assets are for factual/news/documentary/editorial context, not
   ads, product claims, endorsements, or fictionalized implications.
12. Music and SFX may be royalty-free but still trigger Content ID. Keep license
   proof in the project folder.
13. Do not use generated images as fake evidence in documentary/factual videos.
   If a viewer could reasonably mistake a generated image for real footage or a
   real photo, use a real source asset instead or make the generated nature clear
   in the project notes/onscreen treatment.
14. Do not bulk download public OpenStreetMap tiles or geocode large batches
   through public Nominatim. Use a paid provider, cached data extract, or local
   renderer for production map generation.
15. Do not redistribute raw stock files, template source files, loops, or SFX as
   standalone downloads. They must be incorporated into a finished video or
   rendered derivative where the license allows.
