# Visual Planner

Use this after the script draft exists. The visual plan decides what the viewer
sees for each beat before assets are downloaded or generated.

## Output

Create `visual_plan.md` in the project folder using
`knowledge/workflows/content_creation/templates/visual_plan_template.md`.
Read `knowledge_plan.md` first so visual choices use the selected style pack,
skills, technique cards, presets, and QC checklists for the project.

## Visual Layer Types

- A-roll or narrator stand-in.
- Stock/photo/video B-roll.
- Archival evidence.
- Screenshot, article, document, map, or chart.
- Generated illustration or scene plate.
- Kinetic typography.
- Icon/shape system.
- Motion graphics, lower thirds, callouts, or timeline cards.
- Texture, transition, or atmosphere.

## Planning Rules

- One primary visual job per beat.
- Visuals should prove, clarify, dramatize, or rhythmically support the line.
- Use evidence visuals for factual claims whenever possible.
- Use generated visuals for concepts, metaphors, thumbnails, and non-evidence
  scenes only when labeled internally.
- Mark caption-safe regions early.
- Mark motion density: static, subtle, medium, or high.
- Mark whether each beat needs SFX, music emphasis, or silence.

## Beat Fields

For each beat, define:

- Beat ID.
- Voiceover line or phrase.
- Visual purpose.
- Primary visual.
- Secondary overlays.
- Motion treatment.
- Caption treatment.
- Sound treatment.
- Asset IDs or asset requests.
- QC risks.

## Knowledge To Use

Start with the selected visual, motion, caption, sound, and QC route in
`knowledge_plan.md`, then load the relevant files below when present:

- `knowledge/playbooks/motion_graphics.md`
- `knowledge/playbooks/video_typography.md`
- `knowledge/playbooks/kinetic_captions.md`
- `knowledge/playbooks/sound_design.md`
- `knowledge/playbooks/beat_sync.md`
- `knowledge/playbooks/editor_qc.md`

## QC

- Visuals change often enough to support retention without becoming noise.
- Factual beats use evidence or explicitly illustrative visuals.
- Captions and important visuals do not compete for the same screen region.
- Visual plan can be converted into a timeline without guessing.
