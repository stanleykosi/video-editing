# Voiceover Planner

Use this to turn `script.md` into recordable or generatable narration.
Read `knowledge_plan.md` first so pacing, tone, emphasis, and sound-sync rules
match the selected style pack and skills.

## Output

Create a voiceover section in `visual_plan.md` or a separate `voiceover_plan.md`
when the project needs detailed direction.

## Voiceover Decisions

- Human-recorded, synthetic, or temp voice.
- Voice age, tone, pace, accent constraints, and emotional posture.
- Target words per minute.
- Pause placement.
- Emphasis words.
- Retake strategy.
- Pronunciation notes.
- Rights and consent notes for any voice model.

## Pacing Defaults

- Fast short-form: 145-175 WPM.
- Clear educational short: 130-155 WPM.
- Documentary explainer: 115-145 WPM.
- Business/history: 120-150 WPM.
- Sports analysis: 140-170 WPM when energetic, slower for tactical explanation.

## Timing Rules

- Hooks should avoid long pre-roll silence.
- Add breath or pause only when it creates comprehension, tension, humor, or
  emotional weight.
- Mark payoff words for visual and SFX sync.
- Keep sentence endings clean enough for captions and cuts.

## Knowledge To Use

Start with the selected voiceover, pacing, sound, and beat-sync route in
`knowledge_plan.md`, then load the relevant files below when present:

- `knowledge/playbooks/editing_taste_story_pacing.md`

## QC

- Voiceover length matches target duration.
- Pronunciations and names are marked.
- Pauses have a reason.
- Important words have visual beat markers.
- Music/SFX plan leaves speech intelligible.
