# Premiere One-Word Pop-Fade Captions

Use this preset for fast social captions in Premiere-style vertical shorts.

## Suggested Values

- Caption chunking: about 7 characters, max 2 seconds, single line.
- Text style: clean sans font, high contrast, lower-third placement.
- Text size: around 60 in a 1080x1920 sequence as a starting point.
- Start keyframe: position slightly lower than final, opacity 0%.
- End keyframe: final lower-third position, opacity 100%.
- Easing: fast entrance that slows into the final position.

## Rules

- Correct caption wording, timing, line breaks, and placement before upgrading to graphics.
- Remove captions where hook text, B-roll text, or full-screen text already says the same idea.
- Save the Transform effect as a preset only after testing it at phone size.
- Recheck collisions after applying the preset to multiple text layers.
