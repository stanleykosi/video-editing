# Two-Word Social Subtitles

Use this preset for fast, high-energy Shorts, Reels, and TikTok-style edits.

## Suggested Values

- Words per caption: 1-2.
- Premiere one-word variant: about 7 characters, max 2 seconds, single line.
- Line count: single line when the screen also has overlays or visual text.
- Max chunk duration: around 2 seconds for rapid social captions.
- Style support: stroke, shadow, or backing for changing footage.

## Rules

- Apply one caption style, then manually review every chunk.
- Remove captions where visual text already carries the same idea.
- Convert captions to graphic layers only after timing and wording are correct.
- For Premiere pop-fade captions, upgrade to graphics only after caption correction and safe placement.
- Preview at phone size with the full overlay stack visible.
