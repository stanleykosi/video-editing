# CapCut Cutout Walk Cycle

Use this preset for playful cutout characters, objects, or meme/explainer motion.

## Pattern

- Prepare a clean cutout or PNG.
- Add first pose keyframe.
- Move in small position steps.
- Add a tiny vertical bob only if it improves the walk illusion.
- Clear or exit before the cutout blocks the next point.

## QC

- Cutout edge quality fits the project tone.
- Movement reads as intentional, not accidental jitter.
- Path avoids captions, faces, proof, products, and UI.
- Asset rights and likeness are usable for the project.
