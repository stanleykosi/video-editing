# DaVinci Power Bin Preset Workflow

Use this preset to convert checked Resolve effects into reusable editing tools.

## Workflow

- Build the effect on a real short-form section.
- Review it at phone size with captions and crop visible.
- Enable/show Power Bins.
- Create a named bin for the editor, client, or style pack.
- Drag the checked adjustment clip, Text+, flash, overlay, or animation into the bin.
- Rename the preset by job and motion.
- Reuse in a new project and customize text, color, timing, or placement.

## Rules

- Do not save untested effects.
- Keep names practical, such as `zoom_out_broll_fast` or `gradient_text_pop_hook`.
- Delete or archive presets that create duplicate clutter.
