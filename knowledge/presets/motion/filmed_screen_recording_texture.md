# Filmed Screen Recording Texture

Use when a screen recording should feel like it was captured by a camera instead
of a clean digital capture.

## Starting Values

- Place a glass, dust, glare, or monitor texture above the screen recording.
- Scale the texture to cover the full screen region.
- Try Color Burn, Screen, Overlay, or Soft Light depending on the texture.
- Opacity can start around `35-40%`; lower it if UI or source text suffers.

## QC

- UI, source text, captions, and cursor action stay readable.
- Texture has a named job: realism, mood, or transition.
- Texture source/license notes are ready for the asset manifest.
