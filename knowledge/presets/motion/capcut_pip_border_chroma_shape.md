# CapCut PiP Border Chroma Shape

Use when a reaction, tutorial, or gaming video needs a clean picture-in-picture
border around a circular or shaped camera feed.

## Starting Values

- Border asset: clean shape on a key-colored background.
- Key: Chroma Key the background color until only the border remains.
- PiP: apply matching circle or shape mask to the video feed.
- Alignment: scale PiP slightly inside the border so border thickness is even.

## Avoid When

- The PiP blocks gameplay UI, captions, products, proof, or active action.
