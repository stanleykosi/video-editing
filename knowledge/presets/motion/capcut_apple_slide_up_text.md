# CapCut Apple-Style Slide-Up Text

Use this preset for clean premium social text or caption-like emphasis.

## Starting Values

- Font lane: clean bold sans, such as Arial Bold or equivalent.
- Character spacing: around `-1` only after readability holds.
- Duration: about `22 frames` from hidden start to landed text.
- Start: Opacity `0`, text shifted downward.
- Landing: Opacity `100`, final readable position.
- Curve: Cubic Ease on Y movement.
- Shadow: very low opacity, around `7`, only if it improves separation.

## QC

- Text settles before it needs to be read.
- Duplicated compounds have updated words and positions.
- Ordinary captions are suppressed if they duplicate the designed text.
- Text avoids faces, proof, product UI, and CTA regions.
