# CapCut Keyframe Spacing Basics

Use this preset when translating CapCut keyframe edits into reusable agent motion
instructions.

## Pattern

- Start: place a keyframe on the unchanged clip or overlay.
- Property: decide which property owns the move, such as scale, position,
  saturation, filter strength, or volume.
- Change: move the playhead and adjust that same property.
- Speed: move keyframes closer for a snap, farther apart for a slow move.
- Graph: shape the curve after values are set so the move starts, accelerates,
  slows, or stops intentionally.
- Hold: duplicate or hold the final value when the viewer needs to read it.
- Cleanup: delete wrong keyframes instead of leaving hidden drift.

## QC

- Motion has a named job.
- Each changing property has its own start and end keyframe.
- Spacing matches the intended speed.
- Graph shape matches the intended start and end feel.
- Captions, faces, proof, products, UI, and action stay safe.
