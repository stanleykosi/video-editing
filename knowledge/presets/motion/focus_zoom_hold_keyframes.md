# Focus Zoom Hold Keyframes

Use this preset when a screenshot, talking head, object, or action needs clear viewer focus.

## Suggested Values

- Subtle talking-head punch-in: 105-115% scale.
- High-energy statement zoom: 108-125% scale when the crop remains safe.
- CapCut quick zoom: set scale/position, move about 4 frames, change scale and
  position, then hold only if the viewer needs to register the emphasis.
- CapCut slow face zoom: widen spacing and adjust position while scaling so the
  eyes stay in the same screen area.
- Section zoom-out polish: 130% to 100% scale with blur 3 to 0 when the full frame remains safe.
- Optional smooth push-in: 100% to 115% after the settle.
- Stylized CapCut graph zoom stack: first pass can end around 300% scale, second
  re-imported pass around 150%, only when source quality and crop remain safe.
- CapCut motion blur after graph timing lock: start around Blur 10 and Blend 10,
  then reduce if faces, captions, proof, UI, products, or action smear.
- Fast social focus move: 6-12 frames.
- Calm tutorial or explainer move: 12-24 frames.
- Hold after move: at least 12-24 frames, or until the spoken reference is understood.
- Short statement hold: 8-18 frames after the zoom lands.
- Easing: ease into the target unless the style intentionally needs a snap.
- Graphs: choose slow start, fast start, gentle settle, or sharp stop deliberately;
  do not leave the move linear by accident.

## Rules

- Name the focus target before animating.
- Add hold keyframes after the move so the image does not drift.
- Animate scale and position together so the target remains centered.
- Keep the eyes or named focus target stable when the zoom changes scale.
- Preview at delivery size and confirm captions, faces, UI, and proof are not cropped.
- Use zooms for important statements, not filler lines.
- Adjustment-layer zooms must affect only the intended section range.
