# DaVinci Edit Page Keyframe Ease

Use this preset for simple title, position, scale, or opacity moves that do not
need a Fusion node graph.

## Timing

- Start keyframe: object off-position, lower opacity, or pre-move crop.
- End keyframe: final readable position at full opacity or intended scale.
- Speed: closer keyframes are faster; wider spacing is calmer.
- Easing: smooth the landing keyframe and hold if the viewer must read the result.

## QC

- Move lands before or within 2 frames of the spoken reference or visual beat.
- Text or graphic remains readable after the move.
- Keyframes do not drift after the title or object has landed.
- Captions, faces, proof, or UI are not covered by the animated element.
