# DaVinci Fusion Out Cubic Zoom

Use this preset when a Resolve short needs a crisp Fusion zoom or punch move.

## Suggested Values

- Strong B-roll zoom-out: start Size around `1.95`, animate to `1.0` if crop remains safe.
- Text or graphic pop start: `0.3-0.5` scale depending on desired energy.
- Easing: Spline `Out Cubic` as the starting curve.
- Adjust Spline handles so the move starts quickly and settles smoothly.

## Rules

- Use a Transform node for size, position, and angle control.
- Check vertical crop, captions, face, hands, and proof after the move.
- Save as a Power Bin preset only after phone-size QC.
