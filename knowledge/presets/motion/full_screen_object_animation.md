# Full-Screen Object Animation

Use this preset for high-value body moments that need an object, icon, screenshot, or PNG to carry the concept.

## Suggested Values

- Structure: background, main object, support shapes, hierarchy text.
- Object final scale: often 60-70% for a centered vertical-frame PNG, adjusted per asset.
- Object entrance: start larger with 25-35 degrees rotation, settle to final scale and 0 degrees.
- Support shapes: scale 0 to final size with eased motion.
- SFX: one subtle pop or hit on the main object only when speech remains clear.

## Rules

- Reserve this treatment for important concepts, transitions, or payoff lines.
- Use high-resolution cutouts/assets only.
- Remove ordinary captions when hierarchy text already carries the line.
- The main object should read first at phone size.
