# CapCut Overlay Path Slide

Use this preset for stickers, arrows, photos, text, PNGs, or video overlays that
need to enter, point, travel, or exit on a custom path.

## Pattern

- Place overlay offscreen or at route origin.
- Set size, flip, and rotation before path keyframes.
- Keyframe into the focus point or destination.
- Hold long enough to read the callout or route.
- Keyframe out or fade before the next focus competes.

## QC

- Overlay lands on the intended focus.
- Manual path is used only when it beats a simple built-in animation.
- Path does not cover faces, captions, proof, UI, products, or map labels.
- External assets have source/license notes for real projects.
