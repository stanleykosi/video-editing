# Realistic Foley Cutaway Pass

Use this pass when a human cutaway, walk, hand motion, or camera pan feels silent
or disconnected from the physical scene.

## Pattern

- Mark visible steps, hand contacts, object touches, cloth movement, or surface
  cues.
- Add material-matched foley on a separate track.
- Start quiet, then raise only until the action feels believable.
- Fade every tiny sound edge.
- Re-check with dialogue, music, and ambience restored.

## Starting Values

- Sync obvious contacts within `1-2 frames`.
- Start foley `12-18 dB` below dialogue.
- Use short fades on clip edges to prevent clicks.

## QC

- Every cue matches a visible or strongly implied action.
- Foley stays below dialogue.
- The sound improves realism without changing documentary truth.
