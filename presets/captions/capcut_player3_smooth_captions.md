# CapCut Player 3 Smooth Captions

Use this preset when corrected auto captions need a smooth premium CapCut motion
treatment without becoming unreadable.

## Pattern

- Correct auto-caption words, timing, and line breaks first.
- Split captions into short phrase groups.
- Compound each caption group.
- Apply `Player 3` to the first compound.
- Set `Texture` to `0` as a clean starting point.
- Paste attributes to matching caption compounds only after the first one passes QC.

## QC

- Every phrase remains readable at phone size.
- The effect settles before the spoken phrase needs to be read.
- Captions avoid faces, product UI, proof, and designed text.
- Pasted attributes are reviewed on every caption group.
