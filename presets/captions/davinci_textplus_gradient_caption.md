# DaVinci Text+ Gradient Caption

Use this preset for premium Resolve Text+ captions on hook or B-roll emphasis moments.

## Suggested Values

- Use `Text+`, not basic Text, when Fusion control is needed.
- Optional Gaussian Blur: subtle only, enough to soften without reducing readability.
- Text pop scale: start around `0.3`; use `0.1` for a larger slide-up feel.
- Animation length: up to around `50` frames for slower premium movement; shorter for dense hooks.
- Glitch opacity: alternate opacity every `2-3` frames.
- Optional Stop Motion: around `3` for choppy glitch texture.

## Rules

- Use gradient/glow only on emphasis moments.
- Avoid duplicating auto captions unless the duplicate is intentional emphasis.
- Check text over the actual footage at phone size.
