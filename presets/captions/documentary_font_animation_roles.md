# Documentary Font Animation Roles

Use when a documentary/explainer needs title or label text that feels editorial
without copying a publisher identity.

## Font Roles

- Editorial serif: historical gravity, archival titles, chapter words.
- Clean sans: labels, source notes, utility text, screen callouts.
- Display/typewriter style: short emphasis or archival flavor only.
- Condensed bold sans: strong documentary headlines or compact labels.

## Motion

- CapCut documentary title animations can start around `1.5-2s`.
- Cinematic open-style text can start around `1.3s`.
- Settle the animation before the word must be read.

## QC

- One text role owns hierarchy at each moment.
- Captions, title text, and source labels do not compete.
- Font choice supports tone without hiding evidence.
