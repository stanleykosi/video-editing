# CapCut Split-Mask Gradient Text

Use this preset for large minimal title text that needs a subtle premium gradient
or shadow-like tone shift.

## Starting Values

- Base text: high-contrast flat color.
- Duplicate text: slightly lighter or metallic-gray tone.
- Top duplicate: compound before masking.
- Mask: `Split`.
- Feather: around `35` for large title text, then tune by phone-size preview.

## QC

- Duplicate layers are perfectly aligned.
- Feathering does not make letter edges muddy.
- The gradient reads as polish, not reduced contrast.
- Do not use on small accessibility subtitles unless readability is stronger than
  a flat caption style.
