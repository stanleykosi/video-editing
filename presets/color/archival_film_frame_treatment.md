# Archival Film Frame Treatment

Use when footage or photos should read as archival, old media, found footage,
memory, or clearly reconstructed history.

## Starting Values

- Add a film frame or border that does not cover source labels.
- Lower saturation moderately.
- Increase contrast lightly.
- CapCut Particles: start around `50`, then reduce if compression or text suffers.
- CapCut Fade: start around `50`, then reduce if detail becomes muddy.

## QC

- The treatment is truthful for the source type.
- Faces, dates, source text, and captions remain readable.
- Generated or illustrative images are labeled instead of disguised as evidence.
