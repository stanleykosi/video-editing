# Filler Background Text Animation

Use this preset for quick body pattern breaks when a spoken phrase can be represented with centered text.

## Suggested Values

- Background: flat light card with dark text, or colored gradient with white/high-contrast text.
- Text placement: centered unless it hides a proof object or subject.
- Entrance: optional 4-8 frame pop or opacity move.
- Section card entrance: background slide/wipe first, then short title zoom/fade.
- Canvas: design imported cards at the delivery ratio, such as 1920x1080 or
  1080x1920.
- Emphasis: bold, italic, or color only on meaning-changing words.

## Rules

- Use this instead of B-roll only when text alone is enough.
- Remove duplicate subtitles if the centered text carries the same line.
- Keep cards short; return to footage or proof once the phrase has landed.
- Animate both text and background out before body footage resumes.
- Check contrast at phone size before saving as a reusable style.
