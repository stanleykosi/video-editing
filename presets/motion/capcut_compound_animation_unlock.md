# CapCut Compound Animation Unlock

Use this preset when a sticker, text layer, or graphic needs video-style animation
controls that are unavailable on the original layer type.

## Pattern

- Place and style the sticker/text/graphic.
- Set base size, flip, rotation, and position.
- Remove unwanted source in/out animations.
- Create a compound clip from the layer.
- Apply the video-style animation to the compound.
- Reopen the compound if the source layer needs revision.

## QC

- Compounding was necessary; manual keyframes were not the cleaner option.
- The source layer is still editable inside the compound.
- Duplicate source and compound animations do not move the graphic twice.
- Captions, faces, proof, UI, products, and action remain safe.
