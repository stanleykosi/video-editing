# First 3-Second Dynamic Zoom Hook Preset

Use this as a starter preset for feed-first shorts that need immediate motion
without becoming hyper-edited.

## Pattern

- Start on the strongest face, proof frame, or image stack.
- Add a zoom-in, zoom-out, or pan/scale move inside the first 3-5 seconds.
- Hold the final frame long enough for the viewer to read the proof or face.
- Cut or match-cut into the next angle with the focal point still guided.

## Starting Values

- Subtle talking-head push: `100% -> 106-112%`.
- Proof/image stack push: `100% -> 115-130%` only when crop is safe.
- Move duration: `12-30 frames` for crisp social motion.
- Calm hook move: up to `1-3 seconds` when the story wants a slower human feel.
- Hold after move: `8-18 frames` minimum.

## QC

- The hook is clear in the first 3-5 seconds.
- Face, proof, captions, product, and action stay visible.
- Opening speech stays intelligible.
- The later story actually supports the hook.
