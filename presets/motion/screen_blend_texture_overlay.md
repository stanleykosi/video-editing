# Screen Blend Texture Overlay

Use for black-background overlays such as light leaks, dust, sparks,
electricity, fire, glow, atmosphere, or texture accents.

## Starting Values

- Blend mode: Screen or similar.
- Trim: only the highlight, transition, or texture beat.
- Opacity: lower until captions, faces, UI, products, and proof remain readable.
- Placement: if the overlay represents a real source, such as fire, resize and
  position it against that source before judging opacity.
- Optional color/tint: match the project palette.

## Use When

- The overlay highlights a beat, covers a transition, or adds intentional mood.
- A still-image composite needs a black-background moving layer to become part of
  the scene.

## Avoid When

- The overlay is just decoration.
- It creates compression dirt, banding, or caption collisions.
- It does not line up with a plausible source in the base image.
