# Animated Bar Chart Wipe

Use this preset for simple editorial data comparisons.

## Pattern

- Background.
- X/Y axes.
- Axis/category labels.
- Bars built from shapes or text layers.
- Directional wipe/grow animation.
- Stagger by narration order.
- Compound/nest.
- Slide or fade out after read time.

## Starting Values

- Bar wipe duration: around `1 second`.
- Optional bar opacity: around `60%` only when readability holds.
- Stagger: a few frames between bars.

## QC

- Data values and source are known.
- Bar lengths match the data relationship.
- Labels and units are readable.
- Low-FPS texture does not make data unreadable.
