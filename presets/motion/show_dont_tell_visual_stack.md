# Show-Don't-Tell Visual Stack

Use this preset when a short-form explanation needs to visualize spoken concepts quickly.

## Suggested Values

- Text or icon pop-in: 4-8 frames.
- Mask feather: start around 10-40 px depending on resolution and asset edge.
- Highlight color: only on the meaning-changing word.
- Background texture: subordinate to text, icon, stock, and captions.
- Body visual choice: filler card for simple phrases, B-roll text for story/proof beats, full-screen object animation for high-value concepts.

## Rules

- Time every visual element to the spoken concept it represents.
- Use hierarchy: primary idea first, support asset second, texture last.
- Remove captions or simplify them when visual text already carries the idea.
- Clear visual stack elements before the next concept competes for attention.
- Use the simplest visual support that communicates the spoken idea.
