# CapCut SRT Number Count-Up

Use this preset for verified counters, prices, metrics, scores, or result numbers.

## Pattern

- Generate or receive a checked number SRT.
- Import the SRT into CapCut.
- Apply font, size, color, and position to all number captions.
- Compound the number captions.
- Apply a speed curve that starts slow, accelerates, and slows at the end.
- Extend the final number inside the compound for a readable hold.

## QC

- Final number, currency, and unit are correct.
- Counter holds the result long enough to read.
- Counter does not cover captions, faces, product UI, or proof.
- Any ticks stay below speech.
