# CapCut Effect Tail Extension

## Use When

- A stylized effect fades before the intended visual beat finishes.
- A held character moment needs a little more background energy.

## Layer Pattern

`short_effect_tail -> black_backing -> duplicate_effect_layers -> fast_background_slices -> color_match -> trim`

## Suggested Settings

- Use only enough duplicated effect layers to keep the intended tail visible.
- Short background slices around `0.8s` can work as energy texture; retime to the
  song and action readability.
- Color-correct backing clips so they support the foreground subject.
- Clear the extension before the next main action or transition beat.

## QC

- The extension has a named purpose.
- The foreground subject remains readable.
- Background slices feel like texture, not unrelated story shots.
