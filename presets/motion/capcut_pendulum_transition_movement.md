# CapCut Pendulum Transition Movement

## Use When

- A locked high-energy clip needs extra swing before a transition pass.
- The action is already beat-matched and readable.

## Build Pattern

`locked_clip -> pendulum_pass -> optional_second_pass -> readability_check -> transition_pass -> SFX_peak`

## Suggested Rules

- Start with one Pendulum pass.
- Use two passes for strong AMV/action movement.
- Use three only for extreme style after phone-size readability passes.
- Judge the result with the final transition, not as an isolated effect.

## QC

- Swing does not hide the subject, action pose, or captions.
- Strongest motion peak lands on the intended beat or cut.
- SFX lands on the actual movement peak.
