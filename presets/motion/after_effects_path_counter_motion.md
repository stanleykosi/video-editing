# After Effects Path And Counter Motion

Use this preset pattern for progress, growth, process, or system visuals.

## Suggested Values

- Path line: Trim Paths End 0 to 100.
- Icon motion: copy the final shape path into Position after the path is sized.
- Counter: Slider Control linked to Source Text.
- Counter pacing: ease near the final value so the number can be read.

## Rules

- Draw and size the visible path before copying it into Position.
- Sync path, object, and counter motion to the spoken concept.
- Keep captions away from the path and final number.
- Use count/tick SFX only if speech remains clear.
