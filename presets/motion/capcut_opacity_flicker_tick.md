# CapCut Opacity Flicker Tick

Use this preset for a short text flicker accent with optional tick SFX.

## Starting Values

- Six Blend opacity keyframes.
- Fast spacing: `1 frame` apart.
- Opacity pattern: `100 -> 25 -> 50 -> 25 -> 67 -> 100`.
- Slow version: increase keyframe spacing.
- Optional SFX: cut and retime a tick/click so it ends with the flicker.

## QC

- Final frame returns to full readable opacity.
- Tick/click stays below dialogue and clears with the visual.
- Flicker is used on emphasis text, not accessibility subtitles.
- Captions, faces, proof, UI, products, and action remain safe.
