# After Effects Eye-Locked Zoom

Use this preset pattern for hook or statement zooms where the speaker should stay stable.

## Suggested Values

- Hook zoom-out duration: around 1.0-1.5 seconds.
- Dramatic hook start scale: around 185-190% only when the source can survive it.
- Body zooms: use smaller zoom-in/out presets so emphasis does not feel repetitive.
- Easing: Easy Ease plus speed graph shaping.

## Rules

- Put a horizontal guide on the speaker's eyes and keep eyes aligned through the full move.
- Animate Position and Scale together.
- Apply the same motion to original footage and rotoscope/cutout duplicates.
- Parent text to the video only when it should scale with the shot.
