# CapCut Font Shift Loop

Use this preset for a brief font-changing accent on a designed word or phrase.

## Pattern

- Blade the text where the font shift should start.
- Apply a CapCut Loop font-change animation to that segment.
- Blade again for a second loop only when needed.
- Blade and deselect Loop to return to the base font.
- Optional ticking SFX ends with the last font-change frame.

## QC

- The word remains readable through the shift.
- The loop resolves to a stable font.
- The effect is not applied to continuous subtitles.
- Tick/click SFX stays below speech.
