# Documentary Research Overlay Timelapse

Use when the edit needs to show research, editing, browsing, document review, or
source gathering without showing raw screen capture for too long.

## Pattern

`process_recording -> document_overlays -> blend_mode -> optional_speedup -> riser -> context_hold`

## Starting Values

- Speed up only until the process feels active; add holds where text must be read.
- Keep overlay opacity/blend low enough that source words remain readable.
- Use one restrained riser or low tension bed, then fade before the next spoken
  claim.

## QC

- Every visible source supports the claim.
- Private or sensitive details are redacted.
- Captions do not cover document/UI text.
- The final context frame is readable.
