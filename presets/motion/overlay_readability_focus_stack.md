# Overlay Readability Focus Stack

Use this preset when arrows, text, screenshots, or lower thirds need to direct attention without clutter.

## Suggested Values

- Overlay in: 4-8 frames for pop emphasis, 8-16 frames for calmer explainers.
- Background dim: 20-45% opacity when footage competes with text.
- Blur: minimum readable separation only; do not hide evidence.
- Text support: stroke or drop shadow for variable footage; solid backing only when needed.
- Visual-stack hierarchy: primary text/icon first, support asset second, texture/background last.

## Rules

- Keep one primary focus at a time.
- Clear the overlay before the next focal point unless it remains necessary context.
- Check captions, lower thirds, and overlays together for collisions.
- Remove duplicate captions when visual text already carries the spoken concept.
